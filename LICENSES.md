# License and model governance

The repository's software license must be selected by the project owner before public release. Until then, do not assume that public visibility grants permission to reuse the code.

Every model integration must record:
- model and exact checkpoint identifier/hash
- code and weights license separately
- commercial-use and redistribution permissions
- attribution requirements
- voice cloning / consent conditions
- watermarking or output disclosure obligations
- review date and reviewer

Research candidates are not approved for commercial use. In particular, verify XTTS-v2's Coqui Public Model License restrictions, pyannote model access/terms, the precise language coverage and terms for translation/TTS checkpoints, and the status/license of any source-separation model. Never infer checkpoint permissions from a library's license.
